Estou desenvolvendo o JurosBR, uma ferramenta para análise de empréstimos e operações de crédito utilizando Python.

O projeto permite:

• calcular juros simples e compostos;
• converter taxas anuais e mensais;
• calcular parcelas pelo sistema Price;
• estimar o custo total de um empréstimo;
• calcular o impacto dos juros no valor contratado;
• comparar uma proposta com uma taxa de referência;
• gerar uma análise matemática transparente da operação.

A ideia é unir programação, matemática e análise de dados em uma ferramenta simples de utilizar e fácil de auditar por outros desenvolvedores.
